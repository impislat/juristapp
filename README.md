# Правовая помощь — PWA

Мобильный-first PWA на Next.js 14 + Tailwind. Заявки отправляются через серверный route handler в Telegram. Хостинг — Vercel Hobby.

## Важно перед запуском
- Замените имя/описание, цены, контакты и ссылки в `app/page.tsx`.
- Замените демонстрационные отзывы реальными и размещайте их только с разрешения клиентов.
- Добавьте своё фото вместо блока «Ваше фото» в `app/page.tsx`.
- Заполните `/privacy` под реальные процессы обработки данных.
- Этот шаблон не заявляет о статусе адвоката, юридической квалификации, количестве выигранных дел или гарантии результата. Добавляйте только проверяемые факты.
- Для формы нужен серверный endpoint `/api/lead`. **Не отправляйте Telegram Bot Token прямо из браузера**: его украдут. Это не отдельный платный сервер — route handler выполняется на Vercel.

## 1. Локальный запуск
Требуется Node.js 18.17+ (лучше 20).
```bash
npm install
cp .env.example .env.local
# заполните TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
npm run dev
```
Откройте http://localhost:3000. Telegram API из локального сервера доступен при наличии интернета.

## 2. Создать Telegram-бота
1. В Telegram откройте `@BotFather`, отправьте `/newbot`.
2. Укажите имя и username бота, скопируйте токен.
3. Откройте созданного бота и нажмите Start / отправьте `/start`.
4. Чтобы узнать chat ID, временно откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` после сообщения боту. В JSON найдите `message.chat.id`. Никогда не публикуйте этот URL и токен; после настройки не пересылайте его никому. Если getUpdates пуст, отправьте боту ещё одно сообщение и обновите страницу.
5. Если хотите заявки в группу: добавьте туда бота, отправьте сообщение в группе и возьмите `chat.id` из `getUpdates` (для супергруппы обычно отрицательное число).

## 3. Деплой на Vercel
Самый простой способ:
1. Создайте репозиторий на GitHub и загрузите файлы проекта.
2. Войдите на https://vercel.com, нажмите Add New → Project и импортируйте репозиторий.
3. В настройках проекта → Environment Variables добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для Production (при необходимости также Preview).
4. Нажмите Deploy. После изменения переменных или кода выполните redeploy.
5. Откройте URL `https://ваш-проект.vercel.app` и отправьте тестовую заявку.

Альтернатива через CLI:
```bash
npm install
npx vercel
npx vercel env add TELEGRAM_BOT_TOKEN production
npx vercel env add TELEGRAM_CHAT_ID production
npx vercel --prod
```
CLI попросит авторизоваться. При добавлении переменных следуйте подсказкам команды. Бесплатный тариф имеет лимиты и условия Vercel; «бесплатно навсегда» гарантировать нельзя.

## 4. Ссылка и QR-код для Авито
- После деплоя скопируйте публичный `https://...vercel.app` URL.
- Вставьте ссылку в разрешённое правилами Авито место. Не обходите ограничения площадки и не обещайте скидку, если не готовы её предоставить.
- QR-код: откройте URL в генераторе QR-кодов или создайте через системную функцию браузера/дизайнерский редактор. Проверьте QR камерой другого телефона.
- Чтобы отслеживать переходы, можно добавить UTM, например `?utm_source=avito&utm_medium=profile&utm_campaign=pwa`. Пока в проекте UTM не записываются в аналитику.

## 5. Установка
- Android: открыть сайт в Chrome → меню → «Установить приложение» или «Добавить на главный экран».
- iPhone: открыть сайт в Safari → «Поделиться» → «На экран Домой».
- Установка зависит от браузера и устройства; кнопка показывает подсказку, если автоматический install prompt недоступен.

## Ограничения PWA
- Сайт должен открываться по HTTPS (Vercel предоставляет HTTPS).
- Push-уведомления OneSignal здесь намеренно не подключены: нужны аккаунт/настройки и согласие пользователя, а поддержка различается между браузерами. Их можно добавить отдельным этапом.
- Service worker кеширует базовую оболочку и не кеширует отправку формы/API.
- Данные заявок не хранятся в собственной БД; они уходят в Telegram. Настройте доступ к чату и хранение данных ответственно.
- Это технический шаблон, а не юридическая консультация по требованиям к сайту, рекламе или персональным данным.
